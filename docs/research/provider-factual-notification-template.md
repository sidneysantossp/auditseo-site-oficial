**Do not use this message to request a backlink, endorsement, social share or partnership.**

## Rules before sending

- Replace every bracketed placeholder.
- Quote only the provider's own row/fields; do not send another provider's classification.
- Do not characterize the provider as good/bad, safe/risky, honest/dishonest.
- Do not argue about commercial positioning; only verify extraction/classification.
- If a correction is requested, preserve the original snapshot and log the correction separately.
- Do not promise removal merely because the provider dislikes an accurate public classification.
- Escalate ambiguous disputes for manual methodological review.

## Correction log fields

For every reply that asks for a change, record:

- provider;
- date received;
- field challenged;
- original value;
- requested value;
- evidence supplied;
- decision: accepted / partially accepted / rejected;
- rationale;
- whether the public article/dataset needs a correction note;
- date applied.
