# AUDITSEO Editorial Roadmap v2

Status: working editorial plan
Date: 2026-09-07

## 1. Strategic rule

The AUDITSEO content program should reinforce one entity association:

**AUDITSEO = Search Intelligence**

Supporting disciplines:

- Technical SEO
- Search AI / GEO
- Entity Authority
- Intent Content Architecture
- Citability
- Search measurement
- Migration / recovery
- Organic growth governance

Do not expand into unrelated editorial verticals simply because they have search demand.

## 2. Evidence constraint

At the time this roadmap was created, the connected Search Console integration did **not** expose an AUDITSEO property. Therefore this roadmap is based on:

1. commercial intent;
2. topical fit with AUDITSEO services;
3. current SERP / market competition observed on 2026-09-07;
4. availability of primary sources or defensible methodology;
5. ability to link the document to an AUDITSEO service or proprietary framework.

Once the AUDITSEO GSC property is connected, reprioritize using impressions, query-page relationships and ranking opportunities.

## 8. Editorial publishing rule

Before creating a new URL, answer:

1. What user question or business decision does this page own?
2. Which canonical pillar does it support?
3. Which service or entity does it strengthen?
4. What evidence can make it materially better than existing SERP content?
5. Is there a primary source, proprietary method, data or experience angle?
6. Could the query be answered by improving an existing page instead?

If question 6 is yes, update the canonical page instead of creating a new URL.

## 10. Measurement after launch

For each document track, when data becomes available:

- indexation status
- impressions
- clicks
- query coverage
- branded vs non-branded impressions
- internal links received
- assisted conversions
- lead source / landing page
- AI referrals when observable
- citations or mentions in monitored Search AI prompt sets
- backlinks / external citations to proprietary methods or data

The goal is not article count. The goal is to increase the number of search and decision contexts in which AUDITSEO is a credible, retrievable and citable source on Search Intelligence.
